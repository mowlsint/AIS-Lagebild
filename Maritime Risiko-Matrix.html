⚠️ Zombieschiffe & Sanktionsumgehung

Zombieschiff:

Ein Schiff mit unbekannter oder unklar registrierter Flagge. Dies ist ein klassisches Zeichen für Sanktionsumgehung oder illegale Aktivitäten, da der Eigentümer und die Verantwortung unklar sind.

Sanktionshistorie (Schiff selbst):

Das Schiff selbst steht auf Sanktionslisten und darf nicht mehr fahren/handeln.

Sanktionsumgehung (Ladung):

Das Schiff wird verwendet, um sanktionierten Waren zu transportieren (z.B. russisches Öl). Das Schiff selbst ist nicht sanktioniert, wird aber für Umgehung missbraucht. Dies ist oft charakteristisch für Shadow-Fleet-Operationen.

⚡ Besonderheit Zombieschiffe:
Zombieschiffe ohne operative Indikatoren erhalten automatisch ein erhöhtes Risiko (mindestens Level 3-4), da die fehlende Flagge selbst schon ein starker Indikator ist.

🚩 Flag-Listen Erklärung

🟡 Grey List (IMO-Beobachtungsliste):

Länder mit Mängeln bei der Hafenkontrolle, aber noch nicht auf der schwarzen Liste. Sie werden beobachtet und können Kandidaten für Shadow-Fleet-Schiffe sein.

🔴 Black List (IMO-Nicht-Einhaltungsliste):

Länder mit schwerwiegenden Mängeln bei der Hafenkontrolle. Ein höheres Risiko für illegale Aktivitäten, da die Kontrolle minimal ist.

⚠️ Unbekannt (Zombieschiff):

Schiffe mit unklar Eigentümerschaft oder flaggenlosen Schiffen. Dies ist ein Zeichen für versteckte oder illegale Aktivitäten.

⚙️ Scoring-Algorithmus (Transparent)

Y-ACHSE: Strukturelle Verdächtigkeit (1-5)

INIT score = 1

IF flag == "unknown-flag" (Zombieschiff)
  IF "sanctions_evasion" CHECKED
    → score = MAX(score, 4)
  ELSE
    → score = MAX(score, 3)

IF flag IN black_list
  → score = MAX(score, 2)

IF flag IN grey_list
  → score = MAX(score, 2)

IF "flag_change" CHECKED
  → score = MAX(score, 4)

IF "black_flag" AND "flag_change" BOTH CHECKED
  → score = 5

IF "kaliningrad" CHECKED
  → score = MAX(score, 3)

IF "sanctions" CHECKED
  → score = MAX(score, 3)

IF "sanctions_evasion" CHECKED
  → score = MAX(score, 3)

IF "opaque" CHECKED
  → score = MAX(score, 3)

IF (flag == black_list) AND "flag_change" AND "kaliningrad"
  → score = 5

RETURN MIN(score, 5)

X-ACHSE: Operative Indikatoren (0-5)

INIT score = 0
INIT maxWeight = 0

criticalIndicators = {
  'multi_loitering': 4,
  'drone': 4,
  'military': 4,
  'uniformed': 4,
  'pmc': 4,
  'boarding': 3,
  'loitering': 3,
  'ais_blackout': 3,
  'known_incident': 3,
  'russian_ports': 2,
  'ais_unnatural': 2
}

FOR EACH checked_indicator:
  weight = criticalIndicators[indicator]
  maxWeight = MAX(maxWeight, weight)

IF zombie AND no_indicators
  → score = 1

ELSE IF no_indicators
  → score = 0

ELSE IF maxWeight >= 4 AND count >= 2
  → score = 5

ELSE IF maxWeight >= 4
  → score = 4

ELSE IF maxWeight >= 3 AND count >= 2
  → score = 3

ELSE IF maxWeight >= 3
  → score = 2

ELSE IF count >= 3
  → score = 2

ELSE
  → score = 1

IF "uniformed" AND "russian_ports" AND "ais_blackout"
  → score = 5 (Hybrid-Pattern erkannt)

RETURN MIN(score, 5)

Flag-Gewichtung (Eingabe)

Zombieschiff (unbekannt)      → weight 4
Black-List-Flaggen             → weight 3
Grey-List-Flaggen              → weight 2
Andere Billigflaggen           → weight 1
EU-Flaggen / Transparent       → weight 0
ℹ️ Algorithmus-Eigenschaften:
• Zombieschiffe: Erhalten automatisch Y≥3, X≥1 (auch ohne Indikatoren)
• Sanktionsumgehung + Zombie: Erzwingt Y≥4
• Hybrid-Pattern: uniformiert + russ. Häfen + AIS-Blackout → X=5
• Transparenz: Alle Scores sind nachvollziehbar und dokumentiert
