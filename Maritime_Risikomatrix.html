⚙️ Scoring-Algorithmus (Aktualisiert & nachvollziehbar)

Y-ACHSE (Struktur 1–5): Grey/Black klar getrennt + leichte Akkumulation mittelstarker Redflags.

Baseline:
- Grey Flag -> mindestens 2
- Black Flag -> mindestens 3
- Zombie (unknown) -> mindestens 3 (plus höher bei sanctions_evasion / sanctions)

Harte Trigger:
- flag_change -> mindestens 4
- sanctions (Schiff sanktioniert) -> mindestens 4
- Kombis (Black + flag_change, Black + flag_change + kaliningrad, Zombie + sanctions) -> 5

Akkumulation:
- mehrere mittlere Strukturhinweise (opaque, class_issue, pi_issue, identity_churn, manager_churn, ...) -> +1 Level

X-ACHSE (Operativ 0–5): maxSeverity + Summe×Confidence + Kombi-Boost (kein Hard-Override).

Inputs:
- severity je Indikator (1..4)
- confidence (0.3/0.6/0.9)

effective = sum(severity) * confidence

Mapping:
- harte Signale (severity 4) -> schnell hoch
- viele moderate Signale -> steigen über effective
- Hybridmuster -> +1 Boost (gedeckelt auf 5)
Output enthält jetzt „Top-3 Gründe“ + Confidence und eine Freitextnotiz pro Schiff (editierbar).
